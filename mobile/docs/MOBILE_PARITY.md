A faixa completa atende ao requisito de IP dinâmico, mas permite HTTP sem TLS para qualquer IP literal e pode exigir justificativa/revisão da App Store; domínios públicos continuam sujeitos ao ATS. O plist foi validado como XML, mas esta máquina Windows não compila nem executa iOS, então é necessária validação em dispositivo/simulador Apple. HTTP não criptografa senha nem sessão e deve ser usado apenas em rede privada/VPN confiável; não usar pela internet pública.
